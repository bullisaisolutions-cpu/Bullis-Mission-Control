# Release Notes — v1.3

## Added
- Mission Control dashboard
- Mission completion and progress tracking
- Rachel contextual encouragement
- Add/delete/reset mission controls
- Persistent mission notes
- Browser speech-to-text support where available
- Exportable JSON backups
- Restore from JSON backups
- Offline caching and installable PWA behavior

## Storage and privacy
All app data remains in the current browser's local storage unless the user exports it.
No server, login, analytics, or external data transmission is included in this release.
